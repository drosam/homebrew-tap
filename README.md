# drosam/homebrew-tap

Homebrew formulae by [@drosam](https://github.com/drosam).

```sh
brew install drosam/tap/hyperkey
brew services start hyperkey
```

| Formula | Description |
| --- | --- |
| [hyperkey](https://github.com/drosam/hyperkey) | Turn caps lock into a hyper key on macOS |

Formulae are bumped automatically by each project's release workflow.
